# landr-cd GitHub integration sandbox

Private disposable repository for the landr-cd promotion and emergency recovery experiment. It contains synthetic source references only, not production workloads or credentials.

The normal GitHub App will propose changes through pull requests. A separate emergency App will test narrowly configured bypass for recovery. Required checks, review approvals and bypass must be validated before the experiment is marked as passed.

No App permission or branch protection is granted merely by creating this repository. All content remains private. Do not install the experiment Apps on production repositories.
